本组图片依据 `info/data/q1.txt`、`q2.txt`、`q3.txt` 及 `info/trace.cpp` 生成，供论文排版使用。

**镜面全部使用矩形多边形绘制。** 参考镜姿为 3 月 21 日太阳时 12:00；按对方追迹器的法向、水平镜边与纵向镜边计算俯视投影，因此矩形方向随镜位变化，第三问的不同尺寸也直接反映在矩形中。

主目录中的布局与空间分布图将矩形符号线性放大为真实投影的 **1.2 倍**，使镜间视觉空隙更小，图中已注明。镜心、圆环半径、镜数、数值计算用的尺寸均未改变。需要展示实际尺度时，使用 `to_scale/` 中的版本。场界和禁区作用于镜心，与 `info` 的算法一致；符号越过边界不应解释为重新检验了真实镜面边界。

`all_figures.pdf` 汇集主目录九组图片，便于浏览。论文插图建议直接使用单张矢量 PDF；Word 可使用 360 dpi PNG；SVG 可继续编辑。并排图建议跨栏排版，单栏需要看清每面矩形时优先使用单独布局图或局部放大图。

`include_figures.tex` 提供六组常用图片的插入代码和图注，路径按从 `final/` 编译设置。使用这些图时，正文算法和结果应对应 `info` 的方案。

图注可以直接采用以下文字（编号由论文排版决定）：

- 第二、三问定日镜场布局与单位面积年均热功率。实线为半径 350 m 的场界，虚线为塔周 100 m 禁布区。矩形按春分日正午镜姿投影绘制，为便于辨认线性放大 1.2 倍，镜心坐标保持原值。
- 第三问镜面面积与安装高度空间分布。左图颜色表示实际镜面面积，右图颜色表示镜面中心安装高度；两图采用相同底座坐标。
- 第三问镜面规格及径向安装高度。镜面宽度统一为 5.75 m，高度采用七种规格；八个径向区间使用六档安装高度，单调不降条件及最外层 6 m 为算法设定。
- 三问月平均热功率及第二、三问单位面积热功率。每月对 21 日五个规定时刻取平均，60 MW 虚线为年均额定要求，并非每个月均必须达到的下限。
- 三问月平均分项效率。各时刻先按实际镜面面积加权，再对当月五个规定时刻取平均。

功率与效率着色来自对方未修改的 C++ 源码重新计算：全部 60 个规定时刻，每镜每时刻 16384 条光线，种子 20260905，太阳半角 0.00465 rad，塔身半径 3.5 m。每问年均功率与 `info/data/expected.json` 的差必须小于 `1e-7 MW`，并检查逐镜功率加总与全场功率一致后才生成图片。本组没有使用我们原论文的布局或光学结果冒充对方方案。

`data/` 保存每时刻及逐镜复算结果，`manifest.json` 保存数据和源码哈希、复算设置、输出清单。原始 `info` 文件与现有正式论文、设计数组均保持不变。

在仓库根目录运行：

```bash
/opt/miniconda3/envs/tf2/bin/python final/info_figures/build_figures.py
```

或在已安装 NumPy、Matplotlib 的环境中使用 `python`。需要本机 C++17 编译器。脚本将从源码编译，不调用附带的 Windows `.exe`。已生成且设置匹配的数据会复用，修改绘图无需重复光学计算。
