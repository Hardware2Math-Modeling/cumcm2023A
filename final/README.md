# 定日镜场建模论文

`paper.pdf` 为完整中文论文，`paper.tex` 为可编辑 LaTeX 源文件。正文、结果表与图形均围绕当前仓库的几何光学模型重新组织和计算，未沿用旧论文中的固定效率结果。

论文共 21 页，含摘要 1 页、正文及参考文献 18 页、复现附录 2 页。

|---|---:|---:|---:|

第二、三问的单侧 95% 数值功率下界分别为 60.0524 MW 和 60.1111 MW。第三问相对问题二的单位面积目标提升 2.955%，总镜面面积减少 2.778%；相对审计前第三问，单位面积目标提高 1.014%。最终镜型从原来的 9 种归并为 5 种，各有 291 至 821 面，安装高度为 3 档。

四组最终复核种子为 `1915721、1916718、1917715、1918712`，每组每镜每时刻 4096 条光线。第一、二问布局不变，显示数值的小幅变化来自更换独立随机化种子。详细改进及对照见 `search_audit.md`。

## 文件

- `paper.tex`：论文正文，包含摘要、假设、符号、模型推导、三问结果、验证、敏感性分析、参考文献与复现附录。
- `tables/`：由最终复核数据自动生成的数字宏和结果表。
- `figures/`：矢量 PDF 图形及对应 PNG。
- `data/`：最终镜场数组、逐镜设计 CSV、逐月与逐时刻指标、独立复核、约束与实验记录。
- `reoptimize.py`：从 `audit/before_revision/` 的固定快照执行塔址重启、高度剖面比较、双向完整轮次、塔址与镜位联动及区域规格统一对照。
- `reproduce.py`：对保存的最终布局重新进行独立精算、收敛与敏感性检验。
- `build_assets.py`：从复核数据生成论文中的全部数字、表格和图形。
- `check_results.py`：检查原始附件哈希、数组、功率恒等式、正文表格数据和逐镜参数的一致性。

## 编译

已有表格与图形时，仅需在本目录运行：

```bash
latexmk -xelatex -outdir=build paper.tex
```

当前源文件使用 macOS 中文字体；在其他系统上可将 `fontset=mac` 改为 `fontset=fandol`，再使用 XeLaTeX 编译。编译不依赖 Python，也不需要重新执行耗时优化。

## 复算

在仓库根目录运行（需要 `requirements.txt` 中的依赖和 C++ 编译器；本机可先执行 `conda activate tf2`）：

```bash
python -m unittest discover -s tests -v
python final/reproduce.py
python final/build_assets.py
python final/check_results.py
```

已有 `data/q2.npz`、`data/q3.npz` 时会保留最终布局并重做验证。若需重现本次补充搜索，先顺序执行 `python final/reoptimize.py q2` 和 `python final/reoptimize.py q3`，再执行上面的复核命令。基准快照保存在 `audit/before_revision/`。空数据目录会从恢复参数执行新版完整搜索；这与从既有异构方案继续搜索的路径不同，不保证得到同一局部解。计算缓存位于仓库 `build/evaluation_cache/`，按布局、模型源码、物理参数、光线数和随机种子寻址。

论文内尺寸和结果存在显示舍入，几何约束和功率校验始终使用完整精度数组。`data/result2.csv`、`data/result3.csv` 按题目要求的八列字段保存完整精度逐镜参数，供复核和导入题目 Excel 模板；原始 `problem/` 文件没有改写。

基准物理假设为均匀太阳圆盘、视半径 4.65 mrad、塔身半径 2 m、理想平面镜、集热器侧面受光。论文明确区分了数值积分误差与物理假设误差，所给结果是限定搜索范围内的可行改进方案。
