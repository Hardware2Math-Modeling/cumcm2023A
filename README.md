# 2023 全国大学生数学建模 A 题：定日镜场计算与优化

这是可运行、可复核的算法工程，不包含论文。以题目给定的 60 个时刻为统计口径，计算真实镜面相互遮挡和有限圆柱集热器截断，再分别优化统一镜型与异构镜型的布局。`problem/` 始终只读。

## 运行

```bash
conda activate tf2
python solve_mirror_field.py all --profile research --workers 4
```

默认输出目录为 `output/validated/`。研究配置使用多阶段搜索、每镜每时刻 4096 条最终光线、4 组独立随机化。完整运行需要持续计算；运行时间取决于布局密度、处理器和验证缓存，不是几秒钟的公式代入。

可以分阶段运行和恢复：

```bash
python solve_mirror_field.py q1 --rays 4096
python solve_mirror_field.py q2 --profile research
python solve_mirror_field.py q2 --profile research --resume
python solve_mirror_field.py q3 --profile research
python solve_mirror_field.py verify --rays 4096 --replicates 4
python -m unittest discover -s tests -v
```

`--resume` 只复用布局初筛记录，晋级候选仍会重新进行完整光学评分。精算缓存依据镜场、物理假设、采样参数和光学源码的 SHA-256 寻址。更改物理模型后不会读取旧模型结果。`smoke` 配置仅作流程调试，不承诺找到达标方案；`standard` 降低搜索量，`research` 为默认配置。

Python 依赖列在 `requirements.txt`，现有 `tf2` 环境即可使用。首次运行用系统 C++ 编译器生成数值加速库，不需要安装 Numba。没有编译器时自动使用 NumPy 参考实现；也可直接调用 `evaluate(..., backend="numpy")`。加速库和计算缓存位于被 Git 忽略的 `build/` 下。

## 模型与求解

- 太阳方向直接使用东、北、天顶三个分量，避免方位角反三角函数分支错误。
- 每面矩形镜的上下边保持水平，法线实时平分太阳中心方向和镜心至集热器中心方向。
- 在镜面与有限太阳圆盘的联合空间中使用扰乱 Sobol 采样。统计入射阴影、反射遮挡、首次命中圆柱侧面的光线能量；端面不计入外表受光面积。
- 阴影和遮挡用逐光线布尔并集统计，截断效率以未被遮挡的反射能量为分母，避免重复扣损。
- 邻居筛选由最高镜面边缘、完整镜面包围球及光束角界推导，不使用任意固定半径或最近 K 面镜近似。
- 第二问搜索塔址、矩形尺寸、安装高度、间距、行距、旋转、相位和布局类型。包含三角交错、分带径向交错、按反射遮挡尺度调整径向间距三类布局；另搜索每带环数。
- 搜索依次采用孤立镜上界、完整相互作用筛选、接近达标布局的容量恢复、提高精度后的差分扰动与坐标搜索。删镜后重新计算相互作用。
- 第三问从第二问出发，实际修改分区尺寸和高度，以新增候选镜恢复容量，并进行位置交换、塔址调整及逐镜微调。每次接受均要求完整模型达标且单位面积功率提高。

详细公式、几何口径、搜索限制和数值验证见 [算法说明](docs/algorithm.md)。本工程不声称证明非凸问题的全局最优，也不以“国一”作为未经验证的质量标签。

## 输出

通过最终验证后，输出目录包含：

| 文件 | 内容 |
|---|---|
| `result2.xlsx` / `result3.xlsx` | 与题目模板相同的 8 列逐镜设计参数，完整精度存储 |
| `metrics.csv` | 三问的 12 个月效率、功率与单位面积功率 |
| `instantaneous.csv` | 全部 60 个时刻，供独立复核 |
| `q1.npz` / `q2.npz` / `q3.npz` | 精确镜场数组 |
| `q*_optics.npz` | 逐时刻、逐镜光学效率和功率 |
| `verification.json` | 约束、独立随机化误差、原方案同模型对照、输入和源码哈希 |
| `convergence.json` / `sensitivity.json` | 光线数收敛与物理假设敏感性 |
| `q*_search*.json` | 实际搜索过程、接受记录、参数及耗时 |
| `layouts.png` | 三问的空间布局与逐镜单位面积功率 |
| `power_and_convergence.png` | 月均功率与数值收敛 |
| `q3_dimensions.png` | 第三问的异构尺寸和高度 |

在 `verification.json` 中检查第二、三问的 `lower_95_one_sided_kw >= 60000`、全部约束通过，以及第三问独立复核后的目标值是否优于第二问。这里的区间只反映数值积分误差，不能代替物理假设的误差分析。

## 物理假设

题目未给出太阳视半径、太阳圆盘亮度分布、塔身粗细和制造误差。本实现的基准为均匀亮度太阳圆盘、视半径 4.65 mrad、塔身半径 2 m、理想平面镜且无额外面形误差。这些参数均在 `Site` 中显式配置，并输出太阳锥角、塔身粗细和镜面斜率误差的敏感性分析。反射率 0.92、集热器尺寸、塔高、DNI 和大气透射率遵循题目。

为避免场界解释导致不合法，新设计额外采用保守约束：镜面外接圆投影完全处于场界内，并完全避开塔周 100 m 圆盘；所有镜对距离至少为两者较大宽度加 5 m。镜面全俯仰旋转的最低离地间隙严格为正。第一问则原样使用附件坐标。
